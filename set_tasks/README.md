# Т118 — Множества (set)

Файлы:
- `set_tasks.py` — функции заданий 4–9
- `checks.py` — проверки на `assert`
- `answers.md` — ответы на задания 1–3 и 10

Запуск проверок (из папки проекта): 
python checks.py

Если все проверки прошли, в конце выводится `OK: все проверки прошли`. Если какая-то проверка не прошла, Python покажет `AssertionError` и номер строки в `checks.py`.
